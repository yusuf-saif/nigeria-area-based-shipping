# Nigeria Area-Based Shipping (WooCommerce)

Version: **1.3.4**

## Features
- Nigeria-only shipping method (WooCommerce Shipping Method API)
- State default fee + optional Area override fee (custom DB tables, integer kobo)
- Classic checkout: dynamic Area dropdown + instant recalculation
- Checkout Blocks support (defensive integration)
- Admin UI: Setup Wizard, State fees, Areas CRUD, CSV import
- Auto-creates Nigeria shipping zone and enables the method via Wizard
